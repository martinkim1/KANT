# 데이터 리터러시 핵심 요약

> **데이터 리터러시는 데이터를 읽고, 분석하고, 의사결정에 활용하며, 그 근거와 의미를 전달하는 능력이다.**

## 1. 데이터에서 지혜로 이어지는 과정

데이터는 관측한 값 자체다. 여기에 맥락을 붙이면 정보가 되고, 경험과 원칙을 연결하면 지식이 되며, 실제 대응을 결정하면 지혜로 이어진다.

| 구분 | 의미 | 댐 수위 관측 사례 |
| --- | --- | --- |
| **데이터(Data)** | 관찰·측정으로 수집한 사실이나 값 | 수위 `42.3m` |
| **정보(Information)** | 데이터에 목적과 맥락을 부여한 결과 | 수위가 빠르게 상승하며 기준까지 `2.7m` 남음 |
| **지식(Knowledge)** | 정보에 이해·경험·학습을 결합한 통찰과 규칙 | 현재 추세라면 6시간 후 기준을 초과할 가능성이 큼 |
| **지혜(Wisdom)** | 지식을 바탕으로 상황에 맞는 판단과 행동을 선택 | 하류 안전을 고려해 단계적 방류와 경보·대피를 결정 |

**핵심:** 데이터를 많이 모으는 것에서 끝나지 않고, 의미를 해석해 행동으로 연결해야 한다.

## 2. 데이터 리터러시의 네 가지 역량

문해력이 글의 의미와 맥락을 이해하는 능력이듯, 데이터 리터러시는 숫자·표·그래프의 의미와 조건을 이해하고 활용하는 능력이다.

| 역량 | 하는 일 | 핵심 질문 |
| --- | --- | --- |
| **읽기** | 데이터의 의미·구조·단위·기준을 파악 | 이 숫자는 무엇을 의미하는가? |
| **분석** | 비교를 통해 변화·차이·패턴·관계를 파악 | 어떤 변화와 차이가 나타나는가? |
| **활용** | 분석 결과로 실행안을 정하고 효과를 확인 | 이 결과를 바탕으로 무엇을 할 것인가? |
| **커뮤니케이션** | 발견한 사실과 근거를 이해하기 쉽게 전달 | 무엇을 어떤 근거로 설명할 것인가? |

### 2.1 읽기: 숫자의 기준부터 확인한다

예를 들어 **수료율 80%**라는 숫자만으로 교육 성과를 판단할 수 없다.

- **분모:** 전체 신청자인가, 실제 수강을 시작한 사람인가?
- **수료 기준:** 영상 시청 완료인가, 평가 통과인가?
- **범위:** 어느 과정과 어느 기간의 결과인가?

숫자의 크기뿐 아니라 **항목 정의·단위·조사 대상·기간·비교 기준**을 확인해야 한다.

### 2.2 분석: 결과를 나누어 원인을 탐색한다

매출이 줄었다면 다음을 구분해 살펴본다.

- 방문자 수가 줄었는가?
- 방문자 중 구매한 사람의 비율이 낮아졌는가?
- 구매 한 건당 결제 금액이 줄었는가?
- 특정 상품이나 유입 경로에서 감소가 두드러지는가?

이때 데이터의 **오류·누락·비교 조건**도 함께 검토한다.

### 2.3 활용: 실행하고 효과를 확인한다

모바일 방문자의 구매 비율이 낮아졌다면 다음 순서로 대응한다.

1. 모바일 구매 과정의 불편을 점검한다.
2. 점검 결과를 바탕으로 개선안을 만든다.
3. 일부 사용자에게 적용해 기존 방식과 비교한다.
4. 구매 비율과 오류 발생률을 확인하고 적용 범위를 정한다.

**분석 결과 → 실행 → 효과 측정**까지 이어져야 데이터 활용이다.

### 2.4 커뮤니케이션: 사실·해석·제안을 구분한다

| 보고 요소 | 예시 |
| --- | --- |
| 문제 | 매출이 감소했다. |
| 확인한 사실 | 모바일 방문자의 구매 비율이 낮아졌다. |
| 해석과 한계 | 구매 과정의 불편이 원인일 수 있지만, 아직 확인되지 않았다. |
| 제안 | 구매 과정을 점검하고 개선안을 비교 실험한다. |

**핵심:** 확인한 사실과 원인에 대한 추측을 섞지 않고, 불확실성까지 전달한다.

## 3. 데이터 분석 프로세스: CRISP-DM

**CRISP-DM**은 데이터 마이닝 프로젝트를 안내하는 표준적인 절차다. 정식 명칭은 *Cross-Industry Standard Process for Data Mining*이다.

| 단계 | 핵심 업무 | 확인할 질문 |
| --- | --- | --- |
| **1. 비즈니스 이해** | 목표·현황·성공 기준을 정하고 계획 수립 | 어떤 문제를 해결해야 하는가? |
| **2. 데이터 이해** | 초기 데이터 수집·설명·탐색·품질 확인 | 어떤 데이터가 있고 믿을 만한가? |
| **3. 데이터 준비** | 데이터 선택·정제·구성·통합·형식 변환 | 분석에 사용할 형태로 준비됐는가? |
| **4. 모델링** | 기법 선택·검증 설계·모델 구축·평가 | 어떤 방법으로 분석하거나 예측할 것인가? |
| **5. 평가** | 결과와 전체 과정을 검토하고 다음 단계 결정 | 원래 목표를 충족했는가? |
| **6. 배포** | 적용·모니터링·유지보수 계획 및 최종 검토 | 실제 현장에서 어떻게 활용하고 관리할 것인가? |

**핵심:** 모델을 만드는 일은 전체 과정의 일부다. 문제 정의, 데이터 품질, 실제 활용까지 함께 고려해야 한다.

## 4. 데이터 과학과 관련 직무

### 4.1 데이터 과학이란?

데이터에서 의미 있는 통찰과 지식을 얻기 위해 다음 역량을 결합하는 융합 분야다.

- 수학·통계학
- 프로그래밍·컴퓨터 공학
- 인공지능·머신러닝
- 해당 산업과 업무에 대한 **도메인 지식**

데이터 과학자는 데이터를 해석해 복잡한 문제를 해결하고, 산업과 맥락에 대한 이해를 바탕으로 기존 가정도 비판적으로 검토한다.

### 4.2 직무별 역할 비교

아래는 원문에서 제시한 직무 구분을 요약한 것이다.

| 직무 | 주된 역할 | 주요 결과물·핵심 역량 |
| --- | --- | --- |
| **데이터 분석가** | 매출·고객 행동 분석, 지표 관리, 변경 효과 평가 | 보고서·대시보드·개선안 / 문제 정의·SQL·통계·시각화·설명 |
| **데이터 사이언티스트** | 예측 모델링과 실험·검증 | 예측 모델·실험 결과 / Python·통계·머신러닝·데이터 설계·평가 |
| **AI·머신러닝 엔지니어** | 모델 개발·검증과 성능·속도·안정성 개선 | 예측 API·모델 실행 시스템 / 모델 이해·개발·성능 점검 |
| **생성형 AI 서비스 개발자** | 생성형 AI를 활용한 질의응답·업무 자동화 구현 | RAG·AI 에이전트·자동화 기능 / API 활용·검색 및 데이터 연결·평가·오류 처리 |
| **데이터 엔지니어** | 데이터 수집·가공·관리 및 분석·서비스 지원 | 데이터 파이프라인·분석용 데이터마트 / SQL·Python·데이터베이스·데이터 품질 |
| **MLOps 엔지니어** | 모델 개발·배포·모니터링 과정 관리와 자동화 | 모델 운영 환경·자동화 파이프라인 / 버전 관리·모니터링·장애 대응 |

### 4.3 도메인 지식이 중요한 이유

**도메인**은 의료·금융·교육·제조처럼 전문 지식과 경험이 쌓이는 특정 분야를 뜻한다.

강의는 영화 **머니볼**과 **데미스 허사비스** 사례를 통해, 분석 기술과 함께 **무엇을 문제로 정의하고 어떤 질문을 던질지 설계하는 능력**을 강조한다.

## 5. 데이터를 분류하는 세 가지 관점

자료형, 분석 변수의 유형, 데이터 구조는 서로 다른 분류 기준이다.

| 분류 관점 | 무엇을 구분하는가? | 대표 유형 |
| --- | --- | --- |
| **프로그래밍 자료형** | 프로그램에서 값을 표현하는 방식 | `int`, `float`, `str`, `bool` |
| **분석 변수 유형** | 분석할 값의 성질 | 범주형: 명목형·서열형 / 수치형: 이산형·연속형 |
| **데이터 구조** | 데이터가 조직된 형태 | 정형·반정형·비정형 |

### 5.1 변수 유형

다음 정의와 예시는 **보완 설명**이다. 원문에서는 유형을 제시하고 상세 내용은 별도 자료로 안내한다.

| 유형 | 의미 | 예시 |
| --- | --- | --- |
| **명목형** | 순서가 없는 범주 | 혈액형·지역·상품 종류 |
| **서열형** | 순서가 있지만 범주 사이의 간격이 일정하다고 보기 어려움 | 만족도 낮음·보통·높음 |
| **이산형** | 셀 수 있는 수치 | 방문자 수·불량품 수 |
| **연속형** | 연속적인 범위에서 측정하는 수치 | 키·무게·온도 |

### 5.2 데이터 구조

아래 정의 중 반정형 데이터의 예시는 **보완 설명**이다.

| 유형 | 특징 | 예시 |
| --- | --- | --- |
| **정형** | 행·열과 정해진 항목으로 조직됨 | 고객 정보 테이블·매출표 |
| **반정형** | 일정한 구조와 표식이 있지만 고정된 표 형태는 아님 | JSON·XML |
| **비정형** | 고정된 표 구조로 바로 표현하기 어려움 | 영상·음성·텍스트·이미지 |

## 6. 통계의 기초 개념

통계학은 데이터를 수집·분석·해석·표현하는 과정을 다룬다.

### 6.1 기술통계와 추론통계

원문에서 제시한 두 분류의 의미를 **보완 설명**하면 다음과 같다.

| 구분 | 목적 | 예시 |
| --- | --- | --- |
| **기술통계** | 관측한 데이터의 특징을 요약 | 조사한 1,000명의 평균 나이 계산 |
| **추론통계** | 표본을 이용해 모집단의 특성을 추론 | 조사한 1,000명으로 전체 성인의 특성 추정 |

### 6.2 모집단과 표본

- **모집단:** 연구에서 관심을 갖는 전체 집단. 예: 한국의 모든 성인.
- **표본:** 모집단에서 추출한 일부 집단. 예: 조사에 참여한 성인 1,000명.

전체를 조사하기 어려울 때 표본을 조사해 모집단의 특성을 추론한다.

### 6.3 평균·중앙값·분산·표준편차

| 개념 | 뜻 | 해석할 때 기억할 점 |
| --- | --- | --- |
| **평균** | 모든 값의 합을 데이터 개수로 나눈 값 | 극단적인 값의 영향을 받는다. |
| **중앙값** | 정렬했을 때 가운데에 위치하는 값 | 평균보다 극단값의 영향을 덜 받는다. |
| **분산** | 평균에서 떨어진 정도를 제곱해 요약한 값 | 클수록 값들이 평균에서 넓게 퍼져 있다. |
| **표준편차** | 분산의 제곱근 | 작을수록 평균 주변에 모여 있다. |

> **보완 설명:** 데이터 개수가 짝수일 때 중앙값은 가운데 두 값의 평균이다. 표준편차는 원래 데이터와 같은 단위를 사용한다.

#### 계산 예제: `[2, 4, 6]`

원문 38쪽의 연습 문제를 **전체 데이터에 대한 분산** 기준으로 계산하면 다음과 같다.

| 계산 단계 | 결과 |
| --- | --- |
| 평균 | `(2 + 4 + 6) / 3 = 4` |
| 각 값의 편차 | `-2, 0, 2` |
| 편차의 제곱 | `4, 0, 4` |
| 분산 | `(4 + 0 + 4) / 3 = 8/3 ≈ 2.667` |
| 표준편차 | `√(8/3) ≈ 1.633` |

> **보완 설명:** 표본으로 모집단의 분산을 추정할 때 사용하는 불편표본분산은 편차 제곱의 합을 `n-1`로 나눈다. 이 예제에서는 `8/2 = 4`, 표본표준편차는 `2`다.

### 6.4 확률·가설검정·신뢰구간

| 개념 | 핵심 의미 |
| --- | --- |
| **확률** | 사건이 발생할 가능성을 `0~1` 사이의 값으로 표현 |
| **가설검정** | 표본 데이터를 이용해 모집단에 대한 가설을 평가 |
| **신뢰구간** | 모집단의 평균·비율 같은 모수를 추정하는 구간 |

**보완 설명: 95% 신뢰구간의 해석**

같은 방식으로 표본을 반복 추출해 신뢰구간을 만들면, **그 구간들 중 약 95%가 참된 모수를 포함한다**는 뜻이다. 이미 계산된 특정 구간에 대해 “모수가 들어 있을 확률이 95%”라고 해석하는 것은 빈도주의 신뢰구간의 정확한 설명이 아니다. 원문 37쪽의 표현을 이 의미로 보완해 이해하면 된다.

### 6.5 변동성과 회귀모형

- **변동성:** 데이터가 평균을 기준으로 얼마나 퍼져 있는지 나타내는 성질.
- **SST:** 데이터의 전체 변동성을 나타내는 제곱합.
- **SSR:** 회귀모형이 설명하는 변동성을 나타내는 제곱합. 여기서는 원문의 표기 기준을 따른다.

**보완 설명:** 절편이 있는 일반적인 최소제곱 회귀에서는 `SST = SSR + SSE`로 분해할 수 있다. `SSE`는 모형이 설명하지 못한 잔차의 제곱합이다.

### 6.6 상관관계와 회귀분석

| 개념 | 목적 | 해석 |
| --- | --- | --- |
| **상관관계** | 두 변수가 함께 변하는 관계를 파악 | 원문에서 다루는 상관계수는 `-1~1` 범위 |
| **회귀분석** | 독립변수와 종속변수의 관계를 모형화 | 관계를 분석하고 값을 예측하는 데 활용 |

- 상관계수가 **1에 가까우면** 강한 양의 관계, **-1에 가까우면** 강한 음의 관계를 나타낸다.
- **보완 설명:** 피어슨 상관계수에서 `0`에 가깝다는 것은 선형 관계가 약하다는 뜻이다. 비선형 관계까지 없다는 의미는 아니다.
- **보완 설명:** 상관관계나 회귀 결과만으로 인과관계를 확정할 수는 없다.

## 7. 편향과 통계 해석의 함정

### 7.1 평균의 함정

고객의 평균 연령이 **37.3세**라고 해서 주요 고객이 30대 후반이라는 뜻은 아니다.

원문 사례에서는 고객이 **20대 초반과 50대 초반에 많이 분포**한다. 평균만 보면 실제 고객이 적은 연령대를 주요 타깃으로 잘못 정할 수 있다.

**확인할 것:** 평균과 함께 연령대별 비중, 분포의 모양, 고객이 집중된 구간을 살핀다.

### 7.2 앤스컴 콰르텟: 요약 통계량이 같아도 데이터는 다르다

네 데이터셋은 평균·표준편차·상관계수·회귀식이 같거나 거의 같지만, 산점도로 보면 관계가 크게 다르다.

| 공통적인 요약 수치 | 원문 제시 값 |
| --- | --- |
| X 평균 | 약 `9.00` |
| Y 평균 | 약 `7.50` |
| X 표준편차 | 약 `3.32` |
| Y 표준편차 | 약 `2.03` |
| 상관계수 | 약 `0.816` |
| 회귀식 | `Y = 3.00 + 0.50X` |

시각화하면 선형 관계, 곡선 관계, 이상치의 영향, 한 점에 크게 좌우되는 관계 등의 차이가 드러난다.

**핵심:** 평균·표준편차·상관계수 같은 요약 수치와 함께 **그래프와 개별 관측값**을 확인해야 한다.

### 7.3 심슨의 역설: 집단별 결과와 전체 결과가 뒤집힌다

**심슨의 역설**은 집단별로 관찰한 관계가 데이터를 합쳤을 때 반대로 나타나는 현상이다.

#### 사례: A반과 B반의 시험 합격률

| 수업 전 실력 | A반: 합격자 / 응시자 | A반 합격률 | B반: 합격자 / 응시자 | B반 합격률 |
| --- | --- | --- | --- | --- |
| 높음 | 81 / 90 | 90% | 19 / 20 | **95%** |
| 낮음 | 3 / 10 | 30% | 32 / 80 | **40%** |
| **전체** | **84 / 100** | **84%** | **51 / 100** | **51%** |

실력이 높은 집단과 낮은 집단에서는 모두 **B반**의 합격률이 높지만, 전체 합격률은 **A반**이 높다.

#### 결과가 뒤집히는 이유

- A반은 원래 실력이 높은 학생이 **90%**다.
- B반은 원래 실력이 높은 학생이 **20%**다.
- 전체 합격률에는 각 집단의 합격률뿐 아니라 **집단 구성 비중**도 반영된다.

```text
A반 전체 합격률 = 0.90 × 90% + 0.10 × 30% = 84%
B반 전체 합격률 = 0.20 × 95% + 0.80 × 40% = 51%
```

두 실력 집단의 비중을 각각 50%로 맞추어 비교하면 다음과 같다.

| 구분 | 계산 | 비중을 같게 맞춘 합격률 |
| --- | --- | --- |
| A반 | `0.5 × 90% + 0.5 × 30%` | 60% |
| B반 | `0.5 × 95% + 0.5 × 40%` | **67.5%** |

**해석 원칙:** 전체 비율과 함께 **집단별 비율·인원수·출발 조건**을 확인한다. 이 비교만으로 어느 수업이 더 효과적인지 단정할 수는 없다.

## 8. AI 시대에 필요한 관점

원문 목차에는 ‘AI 시대의 데이터 리터러시’가 포함되어 있지만, 별도 제목의 본문 장으로 상세하게 전개되지는 않는다. 관련 메시지는 데이터 과학·도메인 전문가 설명에서 확인할 수 있다.

- 분석 기술과 함께 **분야에 대한 이해와 맥락 판단**이 필요하다.
- 기존 가정을 그대로 받아들이지 않고 **비판적으로 검토**해야 한다.
- 답을 찾는 능력에서 더 나아가 **해결할 문제와 질문을 설계하는 능력**이 중요하다.

**강의 전체를 연결한 학습 포인트:** AI로 분석 결과를 얻더라도 데이터의 기준, 분석 조건, 집단 구성, 해석의 한계를 확인하고 행동의 근거를 설명할 수 있어야 한다.
