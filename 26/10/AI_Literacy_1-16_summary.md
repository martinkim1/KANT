# AI Literacy 요약: AI 기초부터 LLM까지

> **원본:** DS.Lv1.AILiteracy.pdf  
> **요약 범위:** PDF 1~16페이지, LLM 및 LLaMA 소개까지  
> **정리 방식:** 원문의 핵심 개념을 주제별로 통합하고, 이해를 돕는 간단한 설명을 덧붙임. 목차에만 등장하는 AI 이슈·프롬프트 엔지니어링·AI 활용의 후속 본문은 제외함.

## 1. AI·머신러닝·딥러닝의 관계 (3~5페이지)

### 1.1 개념과 포함 관계

**인공지능(AI) ⊃ 머신러닝(ML) ⊃ 딥러닝(DL)**

| 구분 | 핵심 개념 | 이해하기 쉬운 설명 |
| --- | --- | --- |
| 인공지능, AI | 인간의 지능적 작업을 컴퓨터로 구현하는 넓은 분야 | 인식·예측·판단 등의 작업을 수행하는 기술 |
| 머신러닝, ML | 데이터에서 패턴을 학습하여 예측하거나 판단하는 AI의 하위 분야 | 모든 규칙을 사람이 직접 작성하는 대신 데이터에서 규칙을 학습 |
| 딥러닝, DL | 여러 은닉층을 가진 인공신경망을 사용하는 머신러닝의 하위 분야 | 신경망이 데이터의 복잡한 특징을 단계적으로 학습 |

### 1.2 머신러닝의 세 가지 핵심 요소

- **데이터 기반 학습:** 데이터를 통해 입력과 결과 사이의 관계를 학습한다.
- **패턴 인식:** 데이터에서 반복되는 규칙이나 구조를 찾는다.
- **자율적 개선:** 학습 과정에서 모델의 파라미터를 조정하여 성능을 개선한다.

> 학습을 마친 모델이 사용 중 저절로 계속 개선된다는 의미는 아니다. 성능 개선에는 추가 학습이나 갱신 과정이 필요하다.

## 2. 머신러닝의 학습 방식 (6~7페이지)

### 2.1 지도학습과 비지도학습

두 방식은 **학습 데이터에 정답인 레이블(Label)이 있는지**로 구분한다.

| 구분 | 지도학습, Supervised Learning | 비지도학습, Unsupervised Learning |
| --- | --- | --- |
| 학습 데이터 | 입력 데이터와 정답을 함께 제공 | 정답 없이 데이터만 제공 |
| 학습 목적 | 입력으로부터 정답을 예측 | 데이터 내부의 숨겨진 구조나 패턴을 발견 |
| 대표 작업 | 분류, 회귀 | 군집화, 차원 축소, 연관 규칙 발견 |
| 예시 | 스팸 판별, 집값 예측 | 비슷한 고객끼리 묶기, 함께 구매하는 상품 찾기 |

### 2.2 주요 작업의 의미

- **분류(Classification):** 데이터가 어떤 범주에 속하는지 예측한다.
- **회귀(Regression):** 수치 값을 예측한다.
- **군집화(Clustering):** 비슷한 데이터끼리 그룹을 만든다.
- **차원 축소(Dimensionality Reduction):** 데이터의 중요한 정보를 유지하면서 변수의 수를 줄인다.
- **연관 규칙 발견(Association Rule):** 항목 사이에 함께 나타나는 관계를 찾는다.

## 3. 회귀 모델과 분류 모델 (8페이지)

핵심은 **예측 결과가 수치인지, 범주인지**이다.

| 구분 | 회귀 모델 | 분류 모델 |
| --- | --- | --- |
| 예측 대상 | 크기·양 등을 나타내는 수치 | 미리 정해진 범주 |
| 집 관련 예시 | 집값 → 5억 원 | 주택 유형 → 아파트 / 단독주택 |
| 자료에 나온 예시 | 내일 매출 → 300만 원, 배송 시간 → 35분 | 이메일 → 스팸 / 정상, 고객 → 이탈 / 유지, 제품 → 정상 / 불량 |

**자료의 생각해 볼 질문: GPT는 분류 모델일까, 회귀 모델일까?**

- GPT의 기본적인 생성 과정은 문맥을 보고 **다음 토큰의 확률 분포를 예측**하는 것이다.
- 각 단계에서는 어휘 집합의 후보 중 다음 토큰을 선택하므로 다중 분류와 연결해서 이해할 수 있다.
- 이 과정을 반복하여 문장을 생성하므로, 모델 전체는 **생성형 언어 모델**로 이해하는 것이 적절하다.

> 위 GPT 설명은 자료에 제시된 질문에 대한 이해 보충이다. 토큰은 모델이 텍스트를 처리하는 단위로, 단어나 단어의 일부 등에 해당할 수 있다.

## 4. 딥러닝과 전통적인 머신러닝 (9~10페이지)

### 4.1 딥러닝이란?

**여러 은닉층을 가진 인공신경망으로 복잡한 데이터의 특징을 학습하는 방식**이다. 이미지·음성·텍스트처럼 복잡한 비정형 데이터를 다루는 데 널리 활용된다.

### 4.2 특징을 만드는 방식의 차이

| 비교 항목 | 전통적인 머신러닝 | 딥러닝 |
| --- | --- | --- |
| 주요 접근 | 사람이 선택·가공한 특징으로 학습 | 신경망이 데이터에서 특징을 학습 |
| 핵심 개념 | 특징 공학, Feature Engineering | 표현 학습, Representation Learning |
| 주로 활용되는 데이터 | 표 형태의 정형 데이터 | 이미지·음성·텍스트 등의 비정형 데이터 |
| 도메인 지식 | 특징 선택과 가공에 큰 역할 | 데이터 구성·학습 설계·평가에도 필요 |
| 성능을 좌우하는 요소 | 선택한 특징의 품질, 알고리즘, 데이터 | 데이터의 양과 품질, 신경망 구조, 학습 방법 |

**선택 기준:** 데이터의 크기와 특성에 따라 적합한 방식이 달라진다. 딥러닝이 모든 문제에서 항상 우수한 것은 아니다.

> 이해 보충: 전통적인 머신러닝에도 트리와 같은 비선형 모델이 있다. 따라서 두 접근의 차이를 단순히 ‘선형 대 비선형’으로 구분하면 안 된다.

## 5. 인공신경망의 구조와 학습 원리 (11~14페이지)

### 5.1 기본 구성

| 요소 | 역할 |
| --- | --- |
| 입력층, Input Layer | 예측에 사용할 데이터를 받음 |
| 은닉층, Hidden Layer | 입력을 계산하여 중간 표현을 만듦 |
| 출력층, Output Layer | 최종 예측값을 출력 |
| 노드, Node | 입력을 받아 계산하는 단위 |
| 가중치, Weight | 입력이나 노드 사이 연결이 결과에 미치는 영향을 조절하는 값 |

### 5.2 학습이란?

자료의 지도학습 예제에서 학습은 **실제 정답과 모델 예측값의 차이가 작아지도록 파라미터를 반복해서 조정하는 과정**이다.

1. 입력 데이터를 모델에 넣는다.
2. 현재 가중치로 예측값을 계산한다.
3. 예측값과 실제 정답을 비교한다.
4. 오차를 줄이는 방향으로 가중치를 조정한다.
5. 이 과정을 반복하여 적절한 파라미터를 찾는다.

### 5.3 예제: 아파트 가격 예측

자료는 10개의 예시 데이터를 사용하여 아파트의 **평수와 연식으로 가격을 예측**한다.

| 역할 | 변수 | 의미 |
| --- | --- | --- |
| 입력, 독립변수 | `x1` | 아파트 평수 |
| 입력, 독립변수 | `x2` | 아파트 연식 |
| 정답, 종속변수 | `y` | 실제 아파트 가격 |
| 모델 출력 | `y_hat` | 모델이 예측한 가격 |

자료에서 제시한 계산 구조를 단순화하면 다음과 같다.

```text
h1 = w11 × x1 + w12 × x2
h2 = w21 × x1 + w22 × x2

y_hat = w31 × h1 + w41 × h2

오차 = y - y_hat
```

- `h1`, `h2`: 은닉층 노드에서 계산한 값
- `w`: 학습을 통해 조정하는 가중치
- 실제 가격이 `5`, 예측 가격이 `3`이면 자료에서 제시한 오차는 `5 - 3 = 2`이다.

**핵심:** 사람이 가중치를 하나씩 정해 주는 대신, 데이터를 이용한 학습으로 예측에 적합한 가중치를 찾는다.

> 이해 보충: 위 식은 자료의 단순화된 예제다. 일반적인 신경망에는 편향과 활성화 함수도 사용된다. 실제 학습에서는 개별 오차를 손실 함수로 수치화하여 줄인다.

## 6. LLM: 대규모 언어 모델 (15페이지)

### 6.1 정의

**LLM(Large Language Model)**은 대규모 데이터로 학습하여 자연어를 처리하고 생성하는 딥러닝 기반 언어 모델이다.

- **Large:** 많은 파라미터와 대규모 학습 데이터를 사용한다는 의미이다.
- **Language Model:** 문맥을 바탕으로 토큰의 확률을 예측하는 모델이다.
- 자료는 규모의 예로 **GPT-3의 1,750억 개, 즉 175B 파라미터**를 소개한다.

### 6.2 구조와 학습 방식

- 자료는 대표적인 구조로 **Transformer**를 소개한다.
- GPT 계열은 주어진 문맥에서 **다음 토큰을 예측**하는 방식으로 이해할 수 있다.
- BERT 계열은 문장 일부를 가린 뒤 **가려진 토큰을 복원**하는 방식으로 학습한다.

> 이해 보충: GPT와 BERT는 모두 Transformer 계열이지만 구조와 기본 학습 목적이 다르다. 모든 언어 모델이 같은 방식으로 문장을 생성하는 것은 아니다.

### 6.3 주요 활용 기능

| 기능 | 활용 예시 |
| --- | --- |
| 텍스트 생성 | 초안·설명문 작성 |
| 요약 | 긴 문서의 핵심 정리 |
| 번역 | 다른 언어로 내용 변환 |
| 질의응답 | 질문에 대한 답변 생성 |
| 코드 생성 | 코드 초안 작성 |
| 분류 | 텍스트를 주제나 범주로 구분 |

## 7. LLaMA와 공개 모델 생태계 (16페이지)

### 7.1 핵심 내용

자료는 Meta의 **LLaMA 시리즈 공개와 파생 모델의 확산**을 소개한다. 모델 가중치와 관련 코드의 공개는 다른 연구자·개발자가 모델을 활용하고 개선하는 기반이 된다.

### 7.2 자료에서 소개하는 버전 흐름

| 버전 | 공개 시점 | 자료의 주요 설명 |
| --- | --- | --- |
| LLaMA 1 | 2023년 2월 | 연구용 공개, 7B~65B 파라미터 |
| LLaMA 2 | 2023년 7월 | 상업적 활용까지 허용한 공개 모델, 7B·13B·70B 제공 |
| LLaMA 3 | 2024년 4월 | 이전 세대보다 성능을 크게 개선한 모델로 소개 |

- 자료는 파생 모델의 예로 **Alpaca, Vicuna**를 제시한다.
- `B`는 10억을 의미한다. 예를 들어 `7B`는 약 70억 개의 파라미터이다.

> 위 표는 자료에 등장하는 버전의 요약이며 전체 버전 목록은 아니다. ‘공개 모델’이라고 해서 사용 조건이 모두 같은 것은 아니며, 상업적 활용 역시 해당 라이선스의 조건을 따른다.

| 질문 | 핵심 답변 |

| AI·ML·DL의 관계는? | AI 안에 ML, ML 안에 DL이 포함된다. |
| 지도학습과 비지도학습의 차이는? | 학습 데이터에 정답 레이블을 제공하는지 여부이다. |
| 회귀와 분류의 차이는? | 회귀는 수치, 분류는 범주를 예측한다. |

| 자료의 예제에서 학습이란? | 실제값과 예측값의 차이를 줄이도록 가중치를 조정하는 과정이다. |
| 아파트 예제의 입력과 정답은? | 입력은 평수·연식, 정답은 가격이다. |

| LLaMA 공개의 의미는? | 다른 연구자와 개발자의 모델 활용·개선 및 파생 모델 개발 기반이 된다. |
