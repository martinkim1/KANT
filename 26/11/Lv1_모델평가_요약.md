# 모델 평가 요약

이진 분류 모델을 평가할 때는 먼저 **찾고 싶은 대상을 양성으로 지정**한다. 그런 다음 혼동행렬에서 어떤 오류가 발생했는지 세고, 그 오류가 중요한 이유에 맞춰 평가 지표를 선택한다.

## 1. 혼동행렬 읽기

혼동행렬(Confusion Matrix)은 실제값과 예측값의 조합별로 사례 수를 센 표다. 아래는 강의의 10건 예시이며, 양성은 1이다.

| 실제값 ＼ 예측값 | 양성(1) 예측 | 음성(0) 예측 |
|---|---:|---:|
| 실제 양성(1) | TP 4건 · 올바르게 탐지 | FN 2건 · 미탐 |
| 실제 음성(0) | FP 1건 · 오탐 | TN 3건 · 올바르게 제외 |

TP·TN·FP·FN에서 **T/F는 예측이 맞았는지**, **P/N은 모델이 무엇으로 예측했는지**를 뜻한다. 예를 들어 FP(False Positive)는 모델이 양성이라고 예측했지만 실제로는 음성인 경우다. 혼동행렬은 행·열의 클래스 순서에 따라 배치가 달라지므로 숫자를 읽기 전에 축과 라벨을 확인한다.

## 2. 같은 예측 결과를 다섯 가지 지표로 읽기

| 지표 | 답하는 질문 | 공식 | 강의 예시 계산 |
|---|---|---|---|
| 정확도(Accuracy) | 전체 중 몇 건을 맞혔나? | (TP + TN) / 전체 | 7/10 = **70%** |
| 정밀도(Precision) | 양성으로 예측한 사례 중 실제 양성은 얼마나 되나? | TP / (TP + FP) | 4/5 = **80%** |
| 재현율(Recall, 민감도) | 실제 양성 중 얼마나 찾아냈나? | TP / (TP + FN) | 4/6 ≈ **66.7%** |
| 특이도(Specificity) | 실제 음성 중 얼마나 음성으로 판별했나? | TN / (TN + FP) | 3/4 = **75%** |
| F1 점수(F1 Score) | 정밀도와 재현율을 함께 보면 어떤가? | 2 × TP / (2 × TP + FP + FN) | 8/11 ≈ **0.727** |

**정밀도와 재현율은 분자가 같고 분모가 다르다.** 위 모델은 양성이라고 판단한 5건 중 4건을 맞혔다(정밀도). 실제 양성은 6건이므로 그중 2건을 놓쳤다(재현율). 화재 탐지로 생각하면 “울린 경보 중 실제 화재가 몇 건인가?”가 정밀도이고, “발생한 화재 중 몇 건에서 경보가 울렸나?”가 재현율이다.

F1은 정밀도와 재현율의 **조화평균**이다. 정밀도를 P, 재현율을 R이라고 하면 F1 = 2PR / (P + R)이다. 둘 중 하나가 낮으면 F1도 낮은 값의 영향을 크게 받는다. F1만으로는 오탐과 미탐 중 어느 쪽이 문제인지 구별하기 어려우므로 두 지표를 함께 확인한다.

## 3. 클래스별 성능과 평균 해석하기

강의의 다른 예시에서는 179건 중 양성 53건과 음성 93건을 맞혔다. 전체 정확도는 (53 + 93) / 179 = **81.56%**다. 같은 모델이라도 어느 클래스를 관심 대상으로 두느냐에 따라 정밀도가 달라진다.

| 관심 클래스 | 해당 클래스로 예측한 수 | 그중 맞힌 수 | 클래스별 정밀도 |
|---|---:|---:|---:|
| 클래스 1 | 53 + 12 = 65 | 53 | 81.54% |
| 클래스 0 | 93 + 21 = 114 | 93 | 81.58% |

- **Macro avg**는 클래스별 지표를 동일한 비중으로 평균낸다. 소수 클래스도 다수 클래스와 같은 비중을 갖는다.
- **Weighted avg**는 각 클래스의 실제 사례 수(support)를 가중치로 사용한다. 다수 클래스의 성능이 평균에 더 크게 반영된다.

## 4. 클래스 불균형에 대응하기

회원 100명 중 90명이 잔류하고 10명이 이탈한다고 가정하자. 모두 잔류로 예측하면 정확도는 90%지만, 이탈자를 양성으로 두었을 때 재현율은 0/10 = **0%**다. 이탈 방지가 목적이라면 실제 이탈자를 얼마나 찾아냈는지, 연락 대상으로 선정한 회원 중 실제 이탈자가 얼마나 되는지 함께 봐야 한다.

| 접근 | 방법과 주의점 |
|---|---|
| 오버샘플링 | 훈련 데이터에서 소수 클래스 사례를 늘린다. SMOTE는 가까운 소수 클래스 사례 사이에 합성 샘플을 만든다. |
| 언더샘플링 | 훈련 데이터에서 다수 클래스 사례를 줄인다. 제거한 사례에 담긴 정보도 잃을 수 있다. |
| 클래스 가중치 | 소수 클래스 예측이 틀렸을 때 학습 손실에 더 크게 반영되도록 설정한다. |
| 앙상블·특징 선택 | 여러 모델의 예측을 결합하거나 소수 클래스를 구분하는 데 유용한 변수를 선택한 뒤 성능 변화를 비교한다. |
| 평가 | 실제 클래스 비율을 유지한 평가 데이터에서 소수 클래스의 정밀도·재현율·F1과 오탐·미탐 건수를 확인한다. |

## 5. 모델 평가 결과 기록하기

평가표에는 **어떤 조건에서 어떤 점수가 나왔는지**를 함께 남겨야 실험을 비교할 수 있다.

| 기록할 항목 | 예시 |
|---|---|
| 데이터·검증 조건 | 데이터 분할 방식, 교차검증 방법, 사용한 특징, 불균형 처리 방법 |
| 모델·학습 설정 | 알고리즘, 손실 함수, 규제, 학습률, 배치 크기, 학습 횟수, 조기 종료 기준 |
| 결과·판단 | 정확도·F1·손실, 오류 유형, 비교 모델보다 개선된 점, 모델 채택 근거 |

실험 기록과 지표 비교에는 **MLflow·Weights & Biases(W&B)**, 모델 버전 관리에는 **MLflow Model Registry·Amazon SageMaker Model Registry**, 여러 모델이 사용하는 특징 관리에는 **Feast·Tecton**을 활용할 수 있다.
