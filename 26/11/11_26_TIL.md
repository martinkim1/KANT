# 머신러닝 기초 · 앙상블 학습

앙상블(Ensemble)은 여러 기본 모델의 예측을 결합해 새로운 데이터에서 예측의 정확도와 안정성을 높이는 방법이다. 효과를 내려면 개별 모델에 어느 정도 예측력이 있고 **모델들이 서로 다른 사례에서 실수해야 한다.** 모든 모델이 같은 사례에서 같은 방향으로 틀리면 평균을 내도 그 오차가 남는다.

## 1. 배깅·부스팅·스태킹 비교

| 기법 | 각 모델은 무엇을 학습하는가? | 예측을 어떻게 합치는가? | 주로 기대하는 효과 |
|---|---|---|---|
| 배깅(Bagging) | 서로 다르게 뽑은 훈련 표본에서 독립적으로 학습한다. 병렬 학습이 가능하다. | 회귀는 예측값 평균, 분류는 다수결 또는 클래스별 확률 평균을 사용한다. | 훈련 표본이 바뀔 때 예측이 흔들리는 정도인 **분산**을 줄인다. |
| 부스팅(Boosting) | 앞선 모델들이 놓친 부분을 다음 모델이 순차적으로 학습한다. | 모델별 가중 투표를 하거나 기존 예측 점수에 새 모델의 보정값을 더한다. | 단순한 모델이 반복해서 놓치는 패턴을 보완해 **편향**을 줄인다. |
| 스태킹(Stacking) | 여러 기본 모델을 학습하고, 그 예측값과 실제 정답으로 메타 모델을 학습한다. | 메타 모델이 예측을 조합하는 규칙을 배운다. | 서로 다른 모델의 강점을 활용해 일반화 성능을 높인다. |

모델의 다양성을 확보하는 방법으로는 ① 훈련 샘플이나 샘플 가중치 변경, ② 입력 특성이나 분할 후보 변경, ③ 초기값·셔플 등 학습 과정에 무작위성 부여, ④ 알고리즘·구조·하이퍼파라미터 변경이 있다. 다양성의 효과는 검증 데이터에서 확인한다.

## 2. 배깅과 랜덤 포레스트

**배깅 = 부트스트랩 표본 생성 + 모델별 예측 집계.** 부트스트랩은 뽑은 관측치를 다시 뽑을 수 있는 복원추출이다. 원본에서 표본을 여러 번 만들면 같은 행이 한 표본에 여러 번 들어갈 수도 있고, 어떤 표본에서는 빠질 수도 있다. 각 표본으로 모델을 하나씩 학습한다.

강의 예시에서 같은 입력에 대한 다섯 모델의 예측은 20, 80, 45, 65, 30이다. 평균은 **48**이다. 개별 모델의 극단적인 예측이 완화되는 예다. 실제 정답이 주어지지 않았으므로 이 예에서 확인할 수 있는 것은 평균의 안정화 원리까지다.

**랜덤 포레스트(Random Forest)**는 결정 트리들이 서로 다른 판단을 하도록 두 단계에 무작위성을 준다.

1. **트리마다** 부트스트랩으로 훈련에 사용할 행을 뽑는다.
2. **각 노드를 분할할 때마다** 후보 특성을 일부만 무작위로 뽑고, 그 안에서 가장 좋은 분할을 찾는다. 강의 예시는 전체 특성 30개 중 후보 5개를 검토한다.
3. 완성된 트리들의 예측을 결합한다. 여러 트리가 같은 특성에만 의존하는 현상이 줄어 한 트리의 판단에 결과가 과도하게 좌우되는 것을 완화한다.

붓꽃(Iris) 분류 실습에서는 훈련·테스트 데이터를 8:2로 나누고 트리 100개로 학습한 뒤, 테스트 정확도와 특성 중요도를 확인한다. `n_estimators`는 트리 수, `max_features`는 각 노드에서 검토할 후보 특성 수를 조절한다.

강의의 HR 데이터 연습은 동일한 예측 문제에 배깅·부스팅·스태킹을 적용하고 모델을 선택하는 과제다. 같은 데이터 분할과 평가 지표로 기본 모델 대비 개선 폭을 비교하면, **표본 변화에 따른 불안정성을 줄인 효과**, **기존 모델이 놓친 패턴을 보정한 효과**, **서로 다른 예측을 조합한 효과**를 각각 살펴볼 수 있다. 스태킹처럼 학습·추론 단계가 늘어나는 경우에는 성능 개선 폭과 계산 비용을 함께 비교한다.
