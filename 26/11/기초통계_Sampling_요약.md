# 기초통계 — Sampling(표본 추출) 요약

## 1. 샘플링(Sampling)의 개념

### 1.1 샘플링이란?

**샘플링(Sampling)**은 전체 모집단(Population)에서 조사하거나 분석할 일부 대상을 선택하여 표본(Sample)을 구성하는 과정이다.

| 용어 | 의미 |
|---|---|
| 모집단(Population) | 조사하거나 분석하려는 전체 대상 |
| 표본(Sample) | 모집단에서 추출한 일부 데이터 |
| 샘플링(Sampling) | 모집단에서 표본을 추출하는 과정 |
| 대표성(Representativeness) | 표본이 모집단의 특성을 얼마나 잘 반영하는지 |

**핵심 목적:** 모집단 전체를 조사하지 않고도 표본을 활용하여 모집단의 평균, 비율 등 통계적 특성을 추정한다.

### 1.2 샘플링이 필요한 이유

| 목적 | 설명 |
|---|---|
| 시간 및 비용 절약 | 전수조사에 필요한 시간과 비용 감소 |
| 분석 효율 향상 | 대규모 데이터의 분석 및 머신러닝 학습 시간 단축 |
| 데이터 신뢰도 향상 | 적절한 샘플링과 데이터 정제를 통해 불필요한 데이터나 노이즈의 영향 감소 |

**주의:** 샘플링 과정에서는 표본 추출 오차와 편향(Bias)이 발생할 수 있으므로 대표성을 고려해야 한다. 샘플링 자체가 노이즈를 자동으로 제거하는 것은 아니다.

---

## 2. 샘플링의 종류

샘플링은 크게 **확률 샘플링(Probability Sampling)**과 **비확률 샘플링(Non-probability Sampling)**으로 구분된다.

### 2.1 확률 샘플링

모집단의 각 개체가 선택될 확률을 알 수 있는 방식이다.

| 종류 | 추출 방법 | 주요 특징 |
|---|---|---|
| 단순 무작위 샘플링 | 모집단에서 무작위 추출 | 가능한 표본들이 동일한 확률로 선택 |
| 계통 샘플링 | 일정한 간격으로 추출 | 간편하지만 주기성에 따른 편향 가능 |
| 층화 샘플링 | 모집단을 여러 층으로 나누고 각 층에서 무작위 추출 | 집단별 특성과 대표성 고려 |
| 군집 샘플링 | 모집단을 군집으로 나누고 일부 군집을 무작위 선택 | 조사 비용과 접근성 문제 해결 |
| 다단계 샘플링 | 여러 단계에 걸쳐 표본 추출 | 단계별로 서로 다른 추출 방식 적용 가능 |

#### ① 단순 무작위 샘플링(Simple Random Sampling)

- 모집단에서 무작위로 표본을 선택하는 가장 기본적인 방법이다.
- 모집단 크기가 $N$, 표본 크기가 $n$일 때 가능한 크기 $n$의 모든 표본이 동일한 확률로 선택된다(비복원 단순무작위추출 기준).
- 모집단의 평균이나 비율 등을 추정하는 데 활용된다.

#### ② 계통 샘플링(Systematic Sampling)

- 첫 번째 표본을 무작위로 선택한다.
- 이후 일정한 간격으로 표본을 추출한다.
- 모집단 데이터에 주기성이 존재하면 편향이 발생할 수 있다.

**예시**
- 일정한 간격으로 제품 구매 고객 선정
- 공장 생산 라인에서 매시간 제품 품질 검사

#### ③ 층화 샘플링(Stratified Sampling)

- 모집단을 유사한 특성을 가진 여러 층(Stratum)으로 구분한다.
- 각 층에서 단순 무작위 샘플링을 수행한다.
- 모집단 전체뿐 아니라 각 층의 특성도 추정할 수 있다.

**예시:** 연령대별, 성별로 모집단을 나누어 조사

#### ④ 군집 샘플링(Cluster Sampling)

- 모집단을 여러 군집(Cluster)으로 구분한다.
- 일부 군집을 무작위 선택한다.
- 선택된 군집의 모든 구성원을 조사한다.

**특징**
- 전체 모집단의 개별 정보를 확보하기 어려울 때 유용하다.
- 군집 내부 구성원은 이질적이고, 군집 간에는 유사한 특성을 가지는 것이 바람직하다.

#### ⑤ 다단계 샘플링(Multi-stage Sampling)

- 여러 단계로 나누어 표본을 추출한다.
- 예를 들어 1단계에서 지역을 선택하고, 2단계에서 해당 지역의 가구를 선택한다.

### 2.2 비확률 샘플링

표본이 모집단에서 선택될 확률을 정확히 알 수 없는 방식이다. 시간, 비용, 데이터 접근성 등의 제약이 있을 때 사용한다.

| 종류 | 설명 |
|---|---|
| 편의 샘플링(Convenience Sampling) | 접근하기 쉬운 대상을 선택 |
| 판단 샘플링(Judgment Sampling) | 연구자의 판단에 따라 특정 기준을 만족하는 대상 선택 |
| 목적 샘플링(Purposive Sampling) | 연구 목적에 적합한 대상을 의도적으로 선택 |
| 눈덩이 샘플링(Snowball Sampling) | 기존 표본이 다른 대상을 추천하여 표본을 확장 |

**확률 샘플링 vs 비확률 샘플링**

- 확률 샘플링: 대표성과 추정 정확도를 확보하는 데 유리하지만 비용과 노력이 필요하다.
- 비확률 샘플링: 데이터 수집이 쉽고 빠르지만 모집단의 대표성을 확보하기 어렵다.

## 3. 복원 추출과 부트스트랩

### 3.1 복원 추출과 비복원 추출

| 구분 | 복원 추출(With Replacement) | 비복원 추출(Without Replacement) |
|---|---|---|
| 추출 방식 | 선택한 데이터를 다시 넣고 추출 | 선택한 데이터를 제외하고 추출 |
| 중복 선택 | 가능 | 불가능 |
| 특징 | 동일 데이터가 여러 번 선택될 수 있음 | 동일 데이터의 중복 선택 불가 |

### 3.2 부트스트랩(Bootstrap)

**부트스트랩**은 이미 관측한 표본에서 복원 추출을 반복하여 여러 재표본을 생성하고, 통계량이 얼마나 달라지는지 확인하는 방법이다.

**과정**

1. 원본 표본 데이터 준비
2. 복원 추출을 통해 새로운 표본 생성
3. 해당 과정을 반복하여 여러 표본 생성
4. 각 표본에서 통계량을 계산하여 변동성 분석

### 3.3 배깅(Bagging)과 부트스트랩

배깅(Bagging)은 **Bootstrap + Aggregating**의 결합이다.

- 원본 학습 데이터에서 복원 추출로 여러 학습 데이터셋을 생성한다.
- 각각의 데이터셋으로 여러 모델을 학습한다.
- 모델들의 예측 결과를 결합한다.
- 모델 간 다양성(Diversity)을 확보하여 예측 성능과 안정성을 높인다.

## 4. 머신러닝에서의 샘플링

### 4.1 데이터 특성과 분포

- **대규모 데이터:** 샘플링으로 계산 비용과 학습 시간을 줄인다.
- **데이터 편향:** 층화 샘플링 등을 활용하여 범주별 대표성을 고려한다.
- **클래스 불균형:** 오버샘플링과 언더샘플링을 고려한다.

### 4.2 클래스 불균형 대응

분류 문제에서 특정 클래스의 데이터가 지나치게 많은 경우 발생한다.

| 방법 | 설명 |
|---|---|
| 오버샘플링(Oversampling) | 소수 클래스 데이터를 늘리는 방법 |
| 언더샘플링(Undersampling) | 다수 클래스 데이터를 줄이는 방법 |
| 층화 샘플링(Stratified Sampling) | 클래스별 분포를 고려하여 표본 추출 |

### 4.3 샘플링 기법 선택 기준

| 고려 사항 | 핵심 내용 |
|---|---|
| 데이터 크기 및 복잡성 | 계산 비용과 분석 효율 고려 |
| 데이터 분포 | 편향 및 클래스 불균형 확인 |
| 연구 목적 | 정확도와 처리 효율성 사이의 균형 |
| 모델 특성 | 모델의 클래스 불균형 민감도 등 고려 |
| 실행 환경 | 메모리, 연산 리소스, 학습 시간 고려 |
| 대표성 | 모집단의 특성이 충분히 반영되는지 확인 |
| 재현성 | 고정 시드(Random Seed)를 사용하고 과정 기록 |
| 검증 | 교차 검증(Cross Validation)으로 성능 평가 |

## 5. 빅데이터 시대의 샘플링

빅데이터 환경에서도 샘플링은 중요하다.

- 데이터가 많아도 시간, 비용, 계산 자원의 제약이 존재한다.
- 샘플링을 통해 분석 및 모델 학습의 효율성을 높일 수 있다.
- 표본 크기가 커지면 무작위 오차는 감소할 수 있다.
- 그러나 잘못된 데이터 수집 방식에서 발생한 **편향(Bias)은 표본 수를 늘린다고 자동으로 사라지지 않는다.**

즉, **데이터의 양뿐 아니라 표본의 대표성과 샘플링 설계가 중요하다.**

## 6. 핵심 개념 최종 정리

| 개념 | 핵심 내용 |
|---|---|
| Sampling | 모집단에서 일부 표본을 추출 |
| Population | 조사 대상 전체 |
| Sample | 모집단에서 선택된 일부 데이터 |
| Simple Random Sampling | 무작위 표본 추출 |
| Systematic Sampling | 일정한 간격으로 표본 추출 |
| Stratified Sampling | 특성이 유사한 층별로 표본 추출 |
| Cluster Sampling | 일부 군집을 선택하여 조사 |
| Multi-stage Sampling | 여러 단계로 표본 추출 |
| Non-probability Sampling | 선택 확률을 정확히 알 수 없는 추출 |
| With Replacement | 중복 추출 가능 |
| Without Replacement | 중복 추출 불가능 |
| Bootstrap | 복원 추출을 반복하여 재표본 생성 |
| Bagging | 여러 부트스트랩 표본으로 모델 학습 후 결과 결합 |
| Oversampling | 소수 클래스 데이터 증가 |
| Undersampling | 다수 클래스 데이터 감소 |
| Sampling Bias | 표본이 모집단을 제대로 대표하지 못하는 편향 |
| Random Seed | 샘플링 결과의 재현성을 위한 난수 시드 |

**핵심 요약:** 샘플링은 전체 데이터를 모두 사용하지 않고도 효율적으로 분석하기 위한 방법이며, 통계적 추론에서는 대표성, 머신러닝에서는 데이터 분포와 계산 효율을 함께 고려해야 한다.
