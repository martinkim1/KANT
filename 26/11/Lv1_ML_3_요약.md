# 머신러닝 ③ · 군집화, 연관 규칙, 주성분 분석

| 분석할 때 던지는 질문 | 기법 | 얻는 결과 |
| --- | --- | --- |
| 소비 패턴이 비슷한 고객은 누구인가? | 군집화(Clustering) | 고객별 군집 번호 |
| 우유를 산 거래에서 빵도 더 자주 팔리는가? | 연관 규칙 분석(Association Rule Analysis) | 상품 간 규칙과 연관성 지표 |
| 여러 측정값의 차이를 두 축으로 얼마나 설명할 수 있는가? | 주성분 분석(PCA) | 새로운 축에서의 좌표와 설명분산비율 |

세 기법 모두 정답 레이블 없이 데이터의 구조를 탐색한다. 군집화는 **관측 대상**을 묶고, 연관 규칙은 한 거래 안에서 **항목들**이 함께 나타나는 패턴을 찾는다. PCA는 관측 대상을 표현하는 **좌표축**을 바꾼다.

## 1. 군집화와 K-means

K-means는 각 관측값을 가까운 중심점에 배정해 비슷한 관측값끼리 모은다. 군집 수를 뜻하는 **K**는 분석자가 정한다.

1. K를 정하고 초기 중심점 K개를 선택한다.
2. 각 관측값을 가장 가까운 중심점의 군집에 배정한다.
3. 군집별로 소속 관측값의 평균 좌표를 구해 중심점을 옮긴다.
4. 배정과 갱신을 반복해 중심점이 더 이상 거의 움직이지 않으면 종료한다.

### K와 초기 중심점 선택

| 방법 | 살펴보는 값 | 판단 기준 |
| --- | --- | --- |
| 엘보 방법 | 이너셔(Inertia). 각 관측값에서 소속 중심점까지 거리의 제곱합 | K를 늘리면 이너셔는 대체로 감소한다. 감소 폭이 눈에 띄게 줄어드는 지점을 K 후보로 삼는다. |
| 실루엣 점수 | 같은 군집 안의 응집도와 이웃 군집과의 분리도 | 여러 K의 평균 점수를 비교한다. 1에 가까울수록 잘 분리되고, 0 근처는 경계에 있으며, 음수인 점은 다른 군집에 더 가까울 수 있다. |

한 관측값에서 같은 군집의 다른 점들까지의 평균 거리를 **a**라고 한다. 다른 군집마다 그 군집의 점들까지 평균 거리를 구한 뒤, 그중 가장 작은 값을 **b**라고 한다. 실루엣 계수는 **(b − a) / max(a, b)**이다. 예를 들어 a가 2, b가 8이면 점수는 0.75다.

초기 중심점을 무작위로 뽑으면 실행마다 결과가 달라질 수 있다. **K-means++**는 첫 중심점을 무작위로 뽑고, 이후에는 기존 중심점에서 멀리 떨어진 점에 더 높은 선택 확률을 준다.

**실습에서 결과 읽기.** 붓꽃(Iris) 또는 쇼핑몰 고객 데이터에 군집 번호를 붙인 뒤 군집별 특성을 비교한다. 고객 데이터에서는 고객 ID를 식별용으로 두고 연 소득과 소비 점수의 분포를 살펴본다. 군집 번호 자체에는 순위가 없으므로, 실제 분포를 확인한 뒤 ‘고소득·저소비형’처럼 이름을 붙인다. 강의는 다른 군집화 방법으로 계층적 군집화와 밀도 기반 군집화(DBSCAN)도 소개한다.

## 2. 연관 규칙 분석과 Apriori

**A → B**는 A를 포함한 거래에서 B도 함께 나타나는 경향을 표현한다. 장바구니에서는 한 거래에 포함된 상품을 관찰하므로 화살표만으로 구매 순서나 인과관계를 판단할 수 없다.

### 우유 → 빵 규칙 계산

강의 예제는 전체 5건 중 우유가 4건, 빵이 4건, 두 상품을 함께 산 거래가 3건이다.

| 지표 | 답하려는 질문 | 예제 계산 |
| --- | --- | --- |
| 지지도(Support) | 전체 거래 중 두 상품이 함께 나온 비율은? | 3 / 5 = **60%** |
| 신뢰도(Confidence) | 우유를 산 거래 중 빵도 산 비율은? | 3 / 4 = **75%** |
| 향상도(Lift) | 우유를 샀을 때 빵 구매 비율은 평소의 몇 배인가? | 0.75 / 0.80 = **0.9375배** |

신뢰도 75%만 보면 우유 구매자에게 빵을 추천하고 싶지만, 전체 거래의 빵 구매율은 이미 80%다. 이 표본에서는 우유 구매 거래의 빵 구매율이 전체보다 **5%p 낮다**. 향상도가 1보다 크면 독립일 때 예상되는 빈도보다 자주 함께 나타나고, 1이면 예상과 같으며, 1보다 작으면 덜 나타난다.

### Apriori가 후보를 줄이는 원리

품목이 N개면 비어 있지 않은 항목 조합은 **2ᴺ − 1개**다. Apriori는 작은 항목집합부터 지지도를 계산한다. 어떤 조합에 품목을 더하면 그 조합을 모두 포함하는 거래 수는 늘어날 수 없다. 따라서 {우유, 빵}이 최소 지지도에 미달하면 {우유, 빵, 계란}도 검사할 필요가 없다. 이 방식으로 살아남은 빈발 항목집합에서 규칙을 만들고 신뢰도와 향상도를 확인한다.

**텍스트에 적용하기.** 『피노키오』 실습에서는 텍스트 한 줄을 거래 하나, 그 안의 단어를 상품으로 취급한다. 연관 규칙으로 같은 줄에 함께 등장하는 단어를 찾고, 바이그램(bigram) 빈도로 바로 이어지는 두 단어의 반복을 살펴본다.

## 3. 차원과 주성분 분석(PCA)

차원은 **관측값 하나를 표현하는 입력 특성의 수**다. 고객 1,000명을 특성 10개로 기록하면 표본은 1,000개이고 차원은 10개다. 변수를 추가할 때는 새로운 정보가 생기는지, 예측 시점에 사용할 수 있는지, 검증 성능과 계산 비용이 어떻게 달라지는지 확인한다.

| 특성을 다루는 방법 | 예시 |
| --- | --- |
| 특성 추가 | 집값 예측에 역까지의 거리를 추가한다. 면적의 제곱을 추가하면 선형 모델도 곡선 관계를 나타낼 수 있다. |
| 특성 선택 | 면적을 ㎡와 ft²로 모두 기록했다면 한 열만 남긴다. |
| 특성 추출 | 함께 변하는 국어·영어 점수를 조합해 학생 간 전반적인 점수 차이를 나타내는 새 축을 만든다. PCA가 여기에 해당한다. |

### 주성분과 설명분산비율

첫 번째 주성분(PC1)은 데이터를 그 축에 투영했을 때 **분산이 가장 큰 방향**이다. 두 번째 주성분(PC2)은 첫 번째 축과 직교하면서 남은 변동을 가장 많이 담는다. 각 관측값을 선택한 축에 투영하면 더 적은 수의 좌표로 표현할 수 있다.

강의 실습에서 PC1의 설명분산비율은 **72.96%**, PC2는 **22.85%**다. 두 축으로 줄이면 원래 데이터 분산의 **약 95.81%**를 보존한다. 이 수치는 입력 데이터의 퍼짐을 얼마나 유지했는지 나타낸다. 예측에 사용할 때는 축소 전후의 검증 성능을 별도로 비교한다.

- **시각화와 군집 탐색**에서는 여러 특성을 2~3개 주성분으로 압축해 관측값의 분포와 군집의 겹침을 살펴본다.
- **이상치 탐지**에서는 적은 수의 주성분으로 데이터를 복원한 뒤 원래 값과 차이가 큰 관측값을 이상치 후보로 볼 수 있다.
- **계산 비용 절감**을 위해 주성분 수를 줄이면 후속 모델의 입력도 줄어든다. 이때 버리는 방향에 중요한 신호가 있는지 함께 확인한다.
