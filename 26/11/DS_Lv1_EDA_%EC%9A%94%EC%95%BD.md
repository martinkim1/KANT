## 1. EDA란?

**EDA(Exploratory Data Analysis, 탐색적 데이터 분석)**는 데이터의 주요 특징을 **요약·시각화·통계적으로 분석**하여 숨겨진 패턴과 변수 간 관계를 발견하는 과정이다.

### EDA의 주요 목적

| 목적 | 핵심 내용 |
|---|---|
| 데이터 이해 | 구조, 변수의 의미·유형·단위, 분포, 평균·표준편차 파악 |
| 패턴 및 관계 발견 | 변수 간 관련성과 데이터에 나타나는 패턴 탐색 |
| 문제점 식별 | 결측치, 이상치, 중복, 기록 오류·불일치 확인 |
| 가설 생성 및 검증 | 데이터 기반으로 질문과 가설을 설정하고 확인 |
| 분석 기법 선택 | 데이터 특성에 맞는 분석 방법과 모델링 기법 검토 |

- 강의 도입에서는 영화 **《머니볼》(2011)**과 세이버메트릭스를 예시로, 풍부한 데이터를 해석하여 판단에 활용하는 중요성을 소개한다.
- 참고 영상: https://www.youtube.com/watch?v=zjPKa922e4w

## 2. EDA 수행 절차: 8단계

| 단계 | 핵심 질문 | 확인할 항목·방법 |
|---|---|---|
| 1. 구조와 의미 파악 | 한 행과 각 열은 무엇을 의미하는가? | 행·열 수, 변수 설명, 자료형, 단위, 수집 기간 |
| 2. 품질 확인 | 누락·중복·잘못 기록된 값이 있는가? | 결측 비율, 중복 행, 범위·형식 오류 |
| 3. 분포 탐색 | 값은 어디에 몰려 있고 얼마나 흩어져 있는가? | 평균, 중앙값, 표준편차, 분위수, 빈도표, 히스토그램 |
| 4. 이상치 탐색 | 다른 관측치와 크게 다른 값은 무엇인가? | 박스플롯, 산점도, 관측치의 실제 맥락 |
| 5. 변수 간 관계 탐색 | 어떤 변수들이 함께 변하는가? | 산점도, 상관계수, 교차표 |
| 6. 집단별 비교 | 집단별 특징에 차이가 있는가? | 집단별 건수, 평균, 중앙값, 비율 |
| 7. 시간 변화 탐색 | 추세, 계절성 또는 급격한 변화가 있는가? | 시계열 그래프, 일·주·월별 집계 |
| 8. 발견 내용 정리 | 무엇을 알았고 무엇을 더 확인해야 하는가? | 관찰 사실, 가설, 한계, 추가 데이터 |

### 강의 예시: 고객 이탈 데이터

- **구조:** 한 행이 고객 1명인지, 고객의 월별 기록인지 파악한다.
- **품질:** 접속 기록이 없으면 실제 미접속인지 데이터 수집 누락인지 구분한다.
- **분포:** 고객의 이용 횟수와 가입 기간이 어떻게 분포하는지 확인한다.
- **관계:** 이용 횟수와 이탈 여부에 관계가 있는지 탐색한다.
- **집단:** 신규 고객과 장기 고객의 이탈률을 비교한다.
- **시간:** 특정 시점 이후 이탈률이 높아졌는지 살핀다.

## 3. 데이터 분석 프로세스(CRISP-DM)에서 EDA의 역할

강의에서는 EDA가 **모델링 전에 데이터를 이해하는 활동**이면서, 전처리와 모델링 및 배포 단계에서도 반복 활용된다고 설명한다.

| 단계 | EDA 관련 활동 |
|---|---|
| Business Understanding(비즈니스 이해) | 목표·성공지표 정의, KPI·타깃 검토, 라벨·데이터 양 및 실현 가능성 점검 |
| Data Understanding(데이터 이해) | 변수 의미·단위·범위 파악, 분포·관계 탐색, 결측·이상치·중복·오류 점검 |
| Data Preparation(데이터 준비) | 전처리 후 데이터 품질과 분포 재확인 |
| Modeling(모델링) | 모델 성능 평가 및 중요 피처 해석 |
| Deployment(배포) | 서비스에서 수집되는 데이터 분포 확인 |

**핵심:** EDA는 단 한 번 끝나는 절차가 아니라 분석 과정 중 새로운 질문이 생길 때 다시 수행할 수 있다.

## 4. 변수 수와 데이터 유형에 따른 EDA

- **단변량 분석(Univariate):** 변수 하나의 분포·특성을 분석한다.
- **다변량 분석(Multivariate):** 두 개 이상의 변수 사이의 관계 및 집단별 차이를 분석한다. 두 변수만 다루는 경우는 특히 **이변량 분석(Bivariate)**이라고도 한다.
- **그래픽 분석:** 차트와 그래프로 패턴을 확인한다.
- **비그래픽 분석:** 요약 통계량, 빈도표, 교차표 등의 숫자·표로 분석한다.

| 변수 조합 | 대표적인 분석 방법 |
|---|---|
| 수치형 1개 | 평균·중앙값·사분위수·분산·표준편차, 히스토그램·박스플롯·Q-Q 플롯 |
| 범주형 1개 | 빈도·상대빈도·구성비율, 막대그래프 |
| 범주형 + 수치형 | 범주별 평균·중앙값·범위·산포 비교, 나란한 박스플롯 |
| 범주형 2개 이상 | 교차표, 그룹형 막대그래프 |
| 수치형 2개 이상 | 산점도, 상관계수·공분산, 상관 히트맵, 페어플롯 |
| 시간 정보가 있는 변수 | 시계열 라인 플롯 |

## 5. 단변량 분석(Univariate EDA)

### 5.1 범주형 데이터(Categorical Variable)

- 전체 데이터 수, 범주별 **빈도**, 전체에서 차지하는 **구성비율(상대빈도)**을 확인한다.
- **그래픽:** 막대그래프.
- **비그래픽:** 빈도표 및 상대빈도표.

### 5.2 수치형 데이터(Quantitative Variable)

- **범위:** 최소·최대와 주요 값이 집중된 구간.
- **중심:** 평균, 중앙값, 최빈값.
- **산포:** 분산, 표준편차, 범위, 사분위범위(IQR).
- **분포 모양:** 좌우 치우침(왜도), 뾰족한 정도(첨도).
- **데이터 품질:** 이상치, 결측치.
- **그래픽:** 히스토그램, 박스플롯, 바이올린 플롯, Q-Q 플롯.

### 5.3 사분위수와 IQR

정렬된 데이터를 네 구간으로 나누는 기준값:

- **Q1:** 25% 분위수
- **Q2:** 50% 분위수 = 중앙값
- **Q3:** 75% 분위수
- **IQR(사분위범위):** `Q3 - Q1`, 가운데 50% 데이터의 퍼짐을 나타냄

강의의 EDA 개요 실습에서는 **박스플롯, IQR, Z-score**를 이용한 이상치 탐지도 다룬다.

### 5.4 주요 단변량 시각화

| 그래프 | 분석 목적 |
|---|---|
| 히스토그램 | 수치형 변수의 구간별 빈도와 분포 모양 파악 |
| 막대그래프 | 범주별 빈도·차이 비교 |
| 박스플롯(Box plot) | 중앙값, 사분위수, 산포, 이상치 후보 파악 |
| 바이올린 플롯(Violin plot) | 값이 밀집한 구간과 분포 형태 파악 |
| Q-Q 플롯 | 실제 데이터 분위수와 이론적 정규분포 분위수를 비교하여 정규분포와의 적합성 확인 |

**Q-Q 플롯 읽기:** 점들이 대각선 근처에 놓이면 비교 기준인 정규분포와 비교적 잘 맞는다는 뜻이다. 크게 휘거나 벗어나면 꼬리나 분포 형태에 차이가 있을 수 있다.

강의에 포함된 바이올린 플롯 예시:

```python
import matplotlib.pyplot as plt
import seaborn as sns

plt.figure(figsize=(8, 5))
sns.violinplot(x=df["age"], color="skyblue")
plt.title("Violin Plot of Age")
plt.show()
```

## 6. 다변량 분석(Multivariate EDA)

### 6.1 비그래픽 방법: 교차표(Cross-tabulation)

**교차표(분할표)**는 두 개 이상의 변수를 행과 열로 배치하여 각 값의 조합에 해당하는 관측 빈도를 나타낸다.

- **강의 예시:** 딸기 20개의 **과중(무게)**과 **당도**를 구간화해 교차표로 분석한다.
- 가장 많이 나타난 조합은 **과중 22.28~22.86g, 당도 11.93~12.35**로, **20개 중 4개(20%)**다.
- 강의에서는 과중과 당도의 양의 상관관계를 탐색하는 사례로 소개한다.

### 6.2 그래픽 방법

| 그래프 | 용도 |
|---|---|
| 산점도(Scatterplot) | 두 수치형 변수의 관계 확인 |
| 상관관계 히트맵 | 여러 변수 쌍의 상관계수를 색상으로 비교 |
| 페어플롯(Pair plot) | 여러 수치형 변수 쌍의 분포·관계를 한 번에 확인 |
| 평행좌표 플롯(Parallel plot) | 여러 변수에 걸친 각 관측치의 값·패턴 비교 |
| 그룹형 막대그래프 | 범주형 변수들에 따른 집단별 빈도 비교 |

## 7. 상관분석과 상관계수

**상관분석**은 변수 간 관계, 특히 **선형적 관계**의 방향과 강도를 확인하는 방법이다. 강의에서는 피어슨 상관계수(Pearson correlation)를 활용한다.

- 상관계수의 범위: **-1 ~ +1**.
- **양수:** 한 변수가 증가할 때 다른 변수도 증가하는 경향.
- **음수:** 한 변수가 증가할 때 다른 변수는 감소하는 경향.
- **0 부근:** 선형관계가 약함. 비선형 관계가 없다는 뜻은 아님.

강의에 제시된 **상관관계 강도 구분** (계수의 절댓값 기준으로 정리):

| `|r|` 범위 | 강의의 분류 |
|---|---|
| 0.0 ~ 0.2 | 상관관계가 거의 없음 |
| 0.2 ~ 0.4 | 약한 상관관계 |
| 0.4 ~ 0.6 | 상관관계가 있음 |
| 0.6 ~ 0.8 | 강한 상관관계 |
| 0.8 ~ 1.0 | 매우 강한 상관관계 |

> 이 기준은 **강의에서 소개하는 경험적 구분**이며 분야·데이터 맥락에 따라 달라질 수 있다. 상관관계만으로 인과관계가 증명되지는 않는다.

### 타이타닉 생존율 분석 실습 흐름

1. **목표 설정:** 승객의 특성과 생존 여부 간 관계 탐색.
2. **데이터 로드:** Titanic 데이터 불러오기.
3. **품질 확인 및 전처리:** 결측치 확인, 필요에 따라 중앙값·최빈값으로 대체.
4. **기초 탐색:** `info()` 등으로 변수와 기초 정보를 확인.
5. **시각화:** 등급별 생존자 수, 파이·카운트 플롯 등.
6. **상관계수 계산:** 변수 간 또는 특정 변수 쌍의 피어슨 상관계수 확인.
7. **관계 시각화:** 페어플롯과 히트맵으로 결과 해석.
8. **결론 정리:** 생존과 관련성이 높은 변수 및 추가 확인 사항 정리.

강의에 제시된 코드 예시를 실행 가능한 형태로 정리:

```python
# titanic: 수치형 변수들 간 피어슨 상관계수
# 숫자형 열만 대상으로 계산
corr_matrix = titanic.select_dtypes(include="number").corr(method="pearson")

# 강의에서 지정한 두 변수의 상관계수
r = titanic["survived"].corr(titanic["adult_male"].astype(int))

# 생존 여부를 색상으로 구분한 페어플롯
sns.pairplot(titanic, hue="survived")
```

> **코드 관련 참고:** 원본 슬라이드에는 `titanic.corr(method='pearson')`, `titanic['survived'].corr(titanic['adult_male'])`, `sns.pairplot(titanic, hue='survived')`가 소개된다. 위 코드는 숫자형 열 선택과 불리언 형변환을 명시한 예시다. 실제 실행 시 데이터프레임의 열·타입을 확인해야 한다.

## 9. 복습용 핵심 체크리스트

- [ ] EDA의 정의와 목적을 설명할 수 있다.
- [ ] 분석 전에 한 행의 의미와 각 변수의 단위·자료형을 확인한다.
- [ ] 결측치, 중복, 오류, 이상치를 구분해 검토한다.
- [ ] 수치형과 범주형 변수에 맞는 단변량 그래프를 고를 수 있다.
- [ ] Q1, Q2, Q3와 IQR(`Q3-Q1`)의 의미를 안다.
- [ ] Q-Q 플롯의 용도를 설명할 수 있다.
- [ ] 교차표, 산점도, 페어플롯, 평행좌표 플롯의 차이를 안다.
- [ ] 피어슨 상관계수의 부호와 크기를 해석할 수 있다.
- [ ] 상관관계가 인과관계를 의미하지 않음을 이해한다.
- [ ] EDA 결과를 **관찰 사실 / 해석·가설 / 한계 / 후속 분석**으로 정리할 수 있다.
