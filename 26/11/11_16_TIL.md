# LESSON 01. 데이터 분석의 시작: 문제 정의와 분석적 사고

> 데이터 분석 강의 · 첫 번째 수업 요약 (2026-11-16)

## 1. 학습 목표

- 분석을 시작하기 전에 **분석 질문과 목표**를 정의할 수 있다.
- 데이터 분석의 전체 흐름을 설명할 수 있다.
- 데이터에서 발견한 **상관관계**와 **인과관계**를 구분한다.
- 제3의 변수인 **교란변수**와 **심슨의 역설** 가능성을 점검한다.

## 2. 데이터 분석의 전체 과정

**문제 정의 → 데이터 이해 → 품질 진단 → 전처리 → 탐색적 데이터 분석(EDA) → 시각화 → 통계적 검증 → 모델링 전략 → 결과 해석**

| 단계 | 핵심 질문 |
|---|---|
| 문제 정의 | 무엇을 알고 싶고, 어떤 결정을 내릴 것인가? |
| 데이터 이해 | 관측 단위, 변수, 타깃은 무엇인가? |
| 품질 진단 | 결측치·중복·이상치·누수는 있는가? |
| 전처리 | 어떤 정보를 유지하고 어떤 오류를 수정해야 하는가? |
| EDA | 분포·집단 차이·변수 관계는 어떠한가? |
| 시각화 | 어떤 그래프로 패턴을 명확히 드러낼 수 있는가? |
| 통계적 검증 | 관찰한 차이가 우연일 가능성은 어떠한가? |
| 모델링 전략 | 예측이 필요한가? 어떤 검증 방식이 적절한가? |
| 결과 해석 | 무엇을 결론 내릴 수 있고, 무엇은 아직 모르는가? |

> 이 순서는 사고를 돕는 기본 흐름이며, 실제 분석에서는 앞 단계로 돌아가 질문과 방법을 수정할 수 있다.

## 3. 가장 먼저 해야 할 일: 문제 정의

**사례: 학습 서비스 회원 이탈 분석**

- 막연한 질문: “회원 데이터를 분석해 보자.”
- 구체적인 질문: “학습 횟수에 따라 회원 이탈률이 다른가?”
- 후속 질문: “그 차이가 가입 기간 등 다른 변수의 영향 없이도 유지되는가?”

좋은 분석 질문에는 **분석 대상, 비교할 변수, 측정할 결과, 의사결정 목적**이 담겨야 한다.

## 4. 데이터 구조 이해하기

회원 이탈 사례에서 사용할 수 있는 변수의 예시:

| 변수 | 의미 | 분석상 역할 |
|---|---|---|
| `survived` | 0=이탈, 1=잔류 | 결과(타깃) 변수 |
| `StudyCnt` | 학습 횟수 | 설명변수 후보 |
| `Month` | 회원 잔류기간(개월) | 교란변수 후보 |
| `AGE` | 회원 나이 | 추가 설명변수 후보 |

**주의:** 변수 이름만으로 인과적 역할이 확정되지는 않는다. 측정 시점과 수집 방식도 확인해야 한다.

## 5. 실전 판단 연습: CASE 01

**질문 1. 데이터를 받자마자 가장 먼저 할 일은?**

- 선택: **B. 분석 질문과 목표를 구체화한다.**
- 근거: 목표가 있어야 필요한 변수, 품질 점검, 비교 방법과 성과 기준을 결정할 수 있다.

**질문 2. 학습 횟수와 이탈의 관계를 처음 탐색하려면?**

- 선택: **A. 학습 횟수별 이탈률을 비교한다.**
- 근거: 집단별 이탈 비율을 비교하면 관계가 있는지 탐색할 수 있다.
- 한계: 집단 간 차이가 보여도 학습 횟수가 이탈을 *유발했다*고 말할 수는 없다.

## 6. 실전 판단 연습: CASE 02 — 상관관계와 인과관계

**판단:** 현재 정보만으로 학습 횟수가 이탈을 일으킨다고 결론 내리기 어렵다.

왜 그런가?

1. 가입 기간이 긴 회원은 학습 기회가 많고, 이탈 양상도 다를 수 있다.
2. 기존 학습 의욕이나 이용 목적처럼 측정되지 않은 변수가 두 현상에 영향을 줄 수 있다.
3. 이탈이 임박해서 학습 횟수가 감소했을 가능성도 있다(역인과 가능성).

**확인 순서**

1. 학습 횟수와 이탈률의 전체 관계를 살핀다.
2. 가입 기간별로 나누어 동일한 관계가 유지되는지 비교한다(층화 분석).
3. 필요하다면 가입 기간과 다른 설명변수를 함께 고려하는 다변량 로지스틱 회귀를 사용한다.
4. 인과효과를 확인하려면 시간 순서, 교란 통제 및 가능한 경우 무작위 실험 설계를 검토한다.

회귀분석으로 변수를 통제해도 **관측되지 않은 교란**까지 자동으로 해결되지는 않는다.

## 7. 실전 판단 연습: CASE 03 — 심슨의 역설

**선택: B. 전체 관계만으로 판단하지 않고 가입 기간별 관계를 확인한다.**

### 심슨의 역설이란?

각 하위 집단에서 관찰되는 관계가 데이터를 합쳤을 때 약해지거나 반대로 나타나는 현상이다. 집단 구성 비중이 다를 때 발생할 수 있다.

### 회원 이탈 사례에 적용

- 전체 데이터에서는 학습 횟수가 많은 회원의 이탈률이 낮아 보일 수 있다.
- 하지만 가입 기간별로 나누면 그 차이가 줄어들거나 사라질 수 있다.
- 이는 학습 횟수 자체보다 **가입 기간의 차이**가 전체 관계에 영향을 주었을 가능성을 시사한다.

**중요:** 가입 기간은 *교란변수 후보*다. 실제 교란 여부는 변수 사이의 관계와 시간 순서, 도메인 지식을 함께 검토해야 한다. 층화 후 차이가 사라졌다는 사실만으로 원인을 확정할 수는 없다.

## 8. 분석 방법 선택 기준

| 알고 싶은 것 | 우선 고려할 방법 | 해석의 한계 |
|---|---|---|
| 학습 횟수별 이탈률이 다른가? | 그룹별 이탈률 비교, 막대그래프 | 교란변수 미통제 |
| 가입 기간에 따라 관계가 달라지는가? | 가입 기간별 층화 비교 | 작은 집단의 불확실성 |
| 여러 변수의 연관성을 함께 확인할까? | 다변량 로지스틱 회귀 | 인과효과를 자동 보장하지 않음 |
| 학습 횟수를 늘리면 이탈이 줄어드는가? | 인과적 연구 설계, 가능하면 무작위 실험 | 설계·실행의 현실적 제약 |

## 9. 첫 수업 핵심 정리

1. **데이터보다 질문이 먼저다.** 분석 목적에 따라 방법이 달라진다.
2. **전체 평균이나 비율만 믿지 않는다.** 집단 구성이 결과를 왜곡할 수 있다.
3. **상관관계는 인과관계가 아니다.** 교란과 역인과를 검토한다.
4. **교란변수 후보를 찾아 층화 분석한다.** 필요하면 다변량 분석으로 확장한다.
5. **분석 결론의 범위를 명확히 한다.** 확인된 사실, 가설, 추가 검증 과제를 구분한다.

## 10. 복습 질문

1. 회원 이탈 분석에서 모델 학습보다 문제 정의가 먼저인 이유는 무엇인가?
2. 전체 회원에서 학습 횟수와 이탈률이 관련되어 보여도 인과관계를 주장할 수 없는 이유는 무엇인가?
3. 가입 기간별로 나누어 분석했을 때 전체 결과와 달라진다면 어떤 추가 검증을 해야 하는가?
