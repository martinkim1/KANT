## 3. 부스팅 알고리즘

| 알고리즘 | 다음 모델을 학습하는 방식과 특징 |
|---|---|
| AdaBoost | 이전 단계에서 틀린 샘플의 상대적 가중치를 높인다. 분류에서는 각 모델의 가중 오류율에 따라 최종 투표의 영향력을 정한다. |
| Gradient Boosting(GBM) | 현재 예측의 손실을 줄이는 방향으로 새 모델을 학습한다. 제곱오차 회귀에서는 현재 잔차가 다음 모델의 학습 목표가 된다. |
| XGBoost | 손실의 1·2차 미분 정보로 새 트리를 학습하고, 트리 복잡도에 벌점을 준다. 학습률을 곱한 새 트리의 출력을 기존 예측 점수에 더한다. |
| LightGBM | 손실을 가장 많이 줄일 수 있는 리프부터 분할하는 방식(leaf-wise)을 쓴다. 대규모 데이터에서 속도와 메모리 효율이 강점이다. 특정 가지가 지나치게 깊어지면 과적합할 수 있다. |
| CatBoost | 범주형 특성을 지정하면 내부 변환을 지원한다. 수치형 특성과 함께 사용할 수 있어 별도 인코딩 부담을 줄인다. |

### AdaBoost에서 두 가지 가중치 구분하기

- **샘플 가중치**는 다음 모델이 어느 관측치를 더 중요하게 학습할지 정한다. 처음에는 모든 샘플에 같은 가중치를 주고, 각 단계에서 오분류한 샘플의 상대적 비중을 높인다.
- **모델 가중치**는 최종 투표에서 어느 모델의 예측에 더 큰 영향력을 줄지 정한다. 가중 오류율이 낮은 모델에 더 큰 비중을 준다.

예를 들어 다섯 샘플의 가중치가 0.1, 0.1, 0.3, 0.2, 0.3일 때, 어떤 두 개를 틀려도 일반 오류율은 2/5로 같다. 하지만 첫 번째와 두 번째를 틀리면 가중 오류율은 **0.2**, 세 번째와 다섯 번째를 틀리면 **0.6**이다.

### 그래디언트 부스팅에서 잔차 이해하기

정답이 50이고 현재 예측이 40이면 잔차는 **50 − 40 = +10**이다. 제곱오차 회귀에서 다음 모델은 같은 입력을 보고 이 잔차를 예측하도록 학습한다. 반영된 보정값이 +8이면 새 예측은 **48**, 남은 오차는 **2**가 된다. 반대로 정답 30을 35로 높게 예측한 경우에는 음수 방향으로 보정한다.

## 4. 스태킹과 OOF 예측

스태킹에서는 기본 모델의 예측이 메타 모델의 입력 열이 된다. 예를 들어 한 샘플에 대해 로지스틱 회귀, SVM, 결정 트리가 각각 양성 확률 0.7, 0.6, 0.9를 냈고 실제 정답이 1이라면, 메타 모델은 입력 한 행 `[0.7, 0.6, 0.9]`와 목표값 `1`을 받는다.

**OOF(Out-of-Fold) 예측**은 해당 샘플을 훈련에서 제외한 기본 모델이 그 샘플에 대해 낸 예측이다. 기본 모델이 이미 학습한 행에 낸 예측을 그대로 쓰면, 메타 모델은 기본 모델이 새 데이터에서도 그만큼 잘 맞힌다고 학습할 수 있다.

### 강의 예시 · 전체 120개, 5겹 교차검증

1. **데이터 분리** — 훈련용 100개와 최종 테스트용 20개로 나눈다.
2. **OOF 예측 생성** — 훈련용 100개를 20개씩 5개 폴드로 나눈다. 기본 모델마다 80개로 학습하고 제외한 20개를 예측한다. 제외할 폴드를 바꾸며 다섯 번 반복한다.
3. **메타 모델 학습** — 기본 모델 3개가 이진 분류 확률을 하나씩 내면 OOF 입력표는 **100행 × 3열**이 된다. 여기에 훈련용 정답 100개를 짝지어 메타 모델을 학습한다.
4. **최종 예측과 평가** — 기본 모델들을 훈련용 100개 전체로 다시 학습한다. 이들이 테스트용 20개에 낸 예측을 이미 학습한 메타 모델에 전달하고, 최종 출력과 테스트 정답을 비교한다.

일반적인 K겹 교차검증은 폴드별 **평가 점수**를 평균해 성능을 추정한다. 스태킹에서는 각 폴드에서 얻은 **샘플별 예측값**을 원래 행에 맞춰 모으는 것이 중요하다.

실습의 `StackingClassifier`에서 `cv=5`는 OOF 생성에 쓸 폴드 수, `stack_method="predict_proba"`는 기본 모델의 예측 확률 사용, `passthrough=False`는 메타 모델에 기본 모델들의 예측만 전달한다는 뜻이다. 스태킹은 기본 모델을 반복 학습해 계산 비용이 커지고, 추론 시에도 기본 모델과 메타 모델을 모두 거친다.
