## 1. EDA와 데이터 시각화

### EDA란?

**EDA(Exploratory Data Analysis, 탐색적 데이터 분석)**는 통계량과 시각화를 활용해 데이터의 구조, 분포, 패턴, 변수 사이의 관계를 파악하는 과정이다.

- **데이터 이해:** 변수의 의미·자료형·단위·범위와 평균·표준편차 등을 확인한다.
- **패턴 발견:** 값이 몰리는 구간, 시간에 따른 변화, 변수 간 관계를 찾는다.
- **품질 점검:** 결측치, 이상치, 중복, 불일치 등을 발견한다.
- **가설 수립:** 관찰한 특징을 바탕으로 분석할 질문과 가설을 만든다.
- **분석 방향 설정:** 전처리 방법과 적합한 분석·모델링 방법을 결정한다.

시각화와 수치 통계량은 함께 사용해야 한다. 평균이 비슷하더라도 분포 모양이나 이상치의 존재는 다를 수 있다.

### CRISP-DM에서의 역할

CRISP-DM은 데이터 분석 프로젝트를 체계적으로 진행하기 위한 방법론이다. 자료에서는 특히 다음 두 단계에서 EDA의 역할을 강조한다.

| 단계 | EDA의 역할 |
| --- | --- |
| 비즈니스 이해 | 목표·성공지표·타깃을 정의하고, 보유 데이터로 목표를 달성할 수 있는지 검토 |
| 데이터 이해 | 변수 의미와 분포를 확인하고, 관계를 탐색하며 데이터 품질을 검증 |

### 데이터 시각화의 목적

데이터 시각화는 차트·그래프·인포그래픽 등을 사용해 복잡한 정보를 이해하기 쉽게 표현하는 것이다.

1. 분석 전 데이터의 전체적인 모양과 분포를 파악한다.
2. 전처리가 필요한 부분을 발견한다.
3. 분석 결과와 인사이트를 전달한다.
4. 데이터에 근거한 의사결정을 돕는다.

## 3. Matplotlib

Matplotlib은 기본 그래프부터 복잡한 시각화까지 구현할 수 있는 라이브러리다. 축, 제목, 색상, 선 모양 등을 세밀하게 조정하고 PNG·PDF·SVG 등으로 저장할 수 있다.

```python
import matplotlib.pyplot as plt

x = [1, 2, 3, 4]
y = [10, 15, 12, 20]

plt.figure(figsize=(8, 4))
plt.plot(x, y, color="blue", linestyle="--", marker="o", label="Sales")
plt.title("Sales Trend")
plt.xlabel("Quarter")
plt.ylabel("Sales")
plt.grid(True)
plt.legend()
plt.tight_layout()
plt.show()
```

### 주요 함수와 설정

| 기능 | 함수·옵션 | 설명 |
| --- | --- | --- |
| 선 그래프 | `plt.plot(x, y)` | 시간·순서에 따른 변화 |
| 막대그래프 | `plt.bar(x, height)` | 항목 간 크기 비교 |
| 히스토그램 | `plt.hist(data, bins=10)` | 구간별 빈도 표현 |
| 산점도 | `plt.scatter(x, y)` | 두 변수의 관계 |
| 원형 차트 | `plt.pie(values, labels=labels)` | 구성 비율 |
| 박스플롯 | `plt.boxplot(data)` | 사분위수와 이상치 후보 |
| 이미지 표시 | `plt.imshow(image)` | 이미지나 변환 결과 확인 |
| 그림 크기 | `plt.figure(figsize=(8, 4))` | 가로·세로 크기 설정 |
| 제목·축 이름 | `plt.title()`, `plt.xlabel()`, `plt.ylabel()` | 그래프 의미 명시 |

| 범례·격자 | `plt.legend()`, `plt.grid()` | 계열 구분과 값 비교 보조 |
| 특정 값 강조 | `plt.annotate()` | 문자·화살표로 설명 추가 |

- `color`: 선·점 등의 색상.
- `linestyle`: 실선·점선 등 선 모양.
- `marker`: 각 관측값을 표시하는 기호.
- `label`: 범례에 사용할 계열 이름.

### 여러 그래프 배치: subplot

`plt.subplot(행 수, 열 수, 위치)`로 하나의 그림 안에 여러 그래프를 배치한다. 위치 번호는 1부터 시작한다.

```python
plt.figure(figsize=(10, 4))

plt.subplot(1, 2, 1)
plt.plot([1, 2, 3], [2, 4, 3])
plt.title("Trend")

plt.subplot(1, 2, 2)
plt.bar(["A", "B", "C"], [5, 8, 6])

```

도움말은 `help(plt.plot)`으로 확인한다. Jupyter에서는 `plt.plot?`나 `Shift + Tab`도 활용할 수 있다.

## 4. 주요 차트 해석

### 선 그래프

시간에 따른 변화나 추세를 보여준다. 여러 계열을 함께 그리면 그룹별 변화 패턴을 비교할 수 있다. 제목·범례·축 이름을 넣고, 필요하면 격자나 주석으로 주요 변화를 강조한다.

### 막대그래프와 시각화의 함정

범주별 값의 크기를 비교하는 데 적합하다. 다만 축과 기준을 바꾸면 같은 데이터도 다르게 보일 수 있다.

- **일반 눈금:** 실제 금액이나 절대적인 차이를 보여준다.
- **로그 눈금:** 배수에 따른 변화와 상대적인 증가를 비교하는 데 도움이 된다.
- **기준 시점=100:** 서로 출발값이 다른 대상의 증가율을 비교한다.
- **축 생략·절단:** 차이를 과장할 수 있으므로 표시 방식과 범위를 확인한다.

그래프를 읽을 때는 **축의 단위, 범위, 눈금 방식, 기준값**을 먼저 확인한다.

### 도수분포표와 히스토그램

**도수분포표**는 수치 데이터를 여러 구간으로 나눈 뒤 각 구간에 속한 관측값의 개수를 정리한 표다. **히스토그램**은 이러한 분포를 막대로 표현한다.

- `bin`: 데이터를 나눈 구간.
- x축: 수치의 구간.
- y축: 기본 빈도 표현에서는 각 구간에 속한 데이터 수.

예시 데이터: `[162, 164, 165, 166, 168, 170, 171, 174, 176, 179]`

| 구간 | 도수 |
| --- | ---: |
| 160 이상 165 미만 | 2 |
| 165 이상 170 미만 | 3 |
| 170 이상 180 미만 | 5 |
| 합계 | 10 |

구간이 겹치지 않도록 경계를 정하고, 도수 합계가 전체 관측값 수와 같은지 확인한다.

히스토그램에서는 값이 몰린 위치, 분포의 치우침, 퍼짐, 여러 봉우리의 존재를 살핀다. 구간 수와 경계를 바꾸면 모양도 달라지므로 한 가지 설정만으로 판단하지 않는다. 평균·중앙값의 정확한 값은 통계량을 함께 확인한다.

> 보충: 위 예시는 구간 폭이 서로 다르다. 폭이 다른 구간을 히스토그램으로 비교할 때는 막대 높이뿐 아니라 면적과 밀도 표현에도 주의해야 한다.

| 구분 | 히스토그램 | 막대그래프 |
| --- | --- | --- |
| 대상 | 수치형 데이터의 구간별 분포 | 범주별 값 |
| x축 | 수치 구간 | 범주 |
| 순서 | 수치 순서가 의미 있음 | 목적에 따라 범주 순서 변경 가능 |
| 핵심 질문 | 어느 구간에 얼마나 몰려 있는가? | 어느 항목이 더 큰가? |

### 산점도

각 관측값의 두 변수 값을 `(x, y)` 좌표의 점으로 표시한다. 양·음의 상관 경향, 군집, 비선형 패턴, 이상치 후보를 관찰한다. 상관관계가 보인다고 인과관계가 입증되는 것은 아니다.

### 원형 차트

전체에서 각 항목이 차지하는 비율을 보여준다. 항목이 너무 많거나 비율이 비슷하면 비교하기 어려우므로 막대그래프도 고려한다.

## 5. 사분위수, IQR, 박스플롯

### 사분위수와 IQR

사분위수는 데이터를 크기순으로 정렬했을 때 전체를 네 부분으로 나누는 경계값이다.

| 통계량 | 의미 |
| --- | --- |
| Q1 | 약 25% 지점의 값 |
| Q2 | 약 50% 지점의 값, 중앙값 |
| Q3 | 약 75% 지점의 값 |
| IQR | `Q3 - Q1`, 가운데 50%의 데이터가 퍼진 정도 |

일반적인 IQR 기준 이상치 경계는 다음과 같다.

```text
하한 경계 = Q1 - 1.5 × IQR
상한 경계 = Q3 + 1.5 × IQR
```

예를 들어 `Q1=21`, `Q3=35`라면 `IQR=14`, 하한 경계는 `0`, 상한 경계는 `56`이다.

### 박스플롯 읽는 법

- **상자 아래·위 경계:** Q1과 Q3.
- **상자 안의 선:** 중앙값 Q2.
- **상자 길이:** IQR.
- **수염 끝:** 일반적인 1.5×IQR 방식에서는 경계 안에 있는 실제 관측값의 최솟값·최댓값.
- **수염 밖의 점:** 이상치 후보.

> 원문의 경계·수염 설명을 구분해 정리했다. 이론적 경계값과 실제 수염 끝은 다를 수 있으며, 수염 끝이 전체 데이터의 최솟값·최댓값인 것도 아니다. 사분위수 계산 방식에 따라 값이 조금 달라질 수 있다.

이상치 후보를 발견했다고 바로 삭제하지 않는다. 입력 오류인지, 실제로 발생한 드문 사례인지 확인한 뒤 처리한다.

## 6. Seaborn

Seaborn은 Pandas DataFrame과 연동해 통계 시각화를 간결하게 구현할 수 있는 라이브러리다. 분포·관계·범주 비교에 적합하며 기본 스타일과 테마도 제공한다.

### 주요 함수

| 함수 | 용도 | 확인할 내용 |
| --- | --- | --- |
| `sns.histplot()` | 히스토그램 | 구간별 분포 |
| `sns.kdeplot()` | 밀도 추정 곡선 | 부드러운 분포 모양 |
| `sns.boxplot()` | 박스플롯 | 중앙값·사분위수·이상치 후보 |
| `sns.scatterplot()` | 산점도 | 두 변수의 관계 |
| `sns.jointplot()` | 두 변수의 관계와 주변 분포 | 관계와 개별 분포를 함께 확인 |
| `sns.pairplot()` | 여러 변수 쌍의 관계 | 수치형 변수 사이의 패턴을 한꺼번에 탐색 |
| `sns.countplot()` | 범주별 관측 개수 | 각 범주에 데이터가 몇 개 있는지 |
| `sns.barplot()` | 범주별 수치 요약 | 기본적으로 평균과 오차막대를 활용한 비교 |
| `sns.heatmap()` | 행렬을 색으로 표현 | 상관행렬·집계표의 패턴 |

자료의 `distplot`은 히스토그램과 밀도 곡선을 함께 보여주는 예로 소개된다. 같은 학습 목적은 `sns.histplot(data=..., x=..., kde=True)`로 표현할 수 있다.

### hue: 색으로 그룹 추가

`hue`는 변수 값에 따라 색상을 달리해 추가 정보를 표현하는 옵션이다. 자료에서는 요일·성별·식사 시간·흡연 여부 등 범주를 구분하는 데 사용한다.

```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

df = pd.DataFrame({
    "total_bill": [20, 30, 15, 25, 40, 35],
    "tip": [3, 5, 2, 4, 6, 5],
    "time": ["Lunch", "Dinner", "Lunch", "Dinner", "Dinner", "Lunch"],
})

sns.scatterplot(data=df, x="total_bill", y="tip", hue="time")
plt.show()
```

### countplot과 barplot의 차이

- `countplot`: 그룹별 **행의 개수**를 센다.
- `barplot`: 그룹별로 수치형 변수의 **평균 등 요약 통계량**을 비교한다.

예를 들어 요일별 방문 건수는 `countplot`, 요일별 평균 팁은 `barplot`으로 표현할 수 있다. 평균 비교 시에는 표본 수와 오차막대의 의미도 함께 살핀다.

### pivot과 heatmap

`pivot`은 특정 열을 행·열·값으로 재배치해 표 형태를 바꾼다. 집계가 필요하면 `pivot_table`을 활용할 수 있다.

```python
# 범주별 평균 팁을 표로 집계한 뒤 색상으로 표현
table = df.pivot_table(values="tip", index="time", aggfunc="mean")
sns.heatmap(table, annot=True, cmap="Blues")
plt.show()

# 수치형 변수의 상관행렬 시각화
corr = df[["total_bill", "tip"]].corr()
sns.heatmap(corr, annot=True, cmap="coolwarm", vmin=-1, vmax=1)
plt.show()
```

상관행렬에서는 계수의 부호와 크기를 확인한다. 0에 가깝다는 것은 선형 관계가 약하다는 뜻이며, 모든 형태의 관계가 없다는 뜻은 아니다.

## 7. 파생변수와 시각화 실습

자료에서는 Tips 데이터로 **팁 비율**을 만들고 점심·저녁의 평균을 비교하는 실습을 제시한다.

```python
# 청구 금액이 양수인 행에 대해 비율 계산
valid = df.loc[df["total_bill"] > 0].copy()
valid["tip_rate"] = valid["tip"] / valid["total_bill"]

sns.barplot(data=valid, x="time", y="tip_rate")
plt.ylabel("Tip rate")
plt.show()
```

팁 금액과 팁 비율은 서로 다른 질문에 답한다. 금액은 절대적인 크기, 비율은 청구 금액 대비 상대적인 크기를 보여준다.

Titanic 데이터 실습은 적합한 차트를 선택하고 관찰 결과에서 인사이트를 도출하는 과제다. 그래프를 그린 뒤에는 **무엇이 관찰되는지 → 어떤 가설을 세울 수 있는지 → 추가로 무엇을 확인할지**를 정리한다.

## 8. 워드클라우드

워드클라우드는 단어의 빈도나 중요도를 글자 크기 등으로 표현하는 시각화다.

### 기본 작업 흐름

1. 텍스트를 수집한다.
2. 문장부호·불필요한 공백 등을 정리한다.
3. 불용어·조사·의미 없는 표현 등을 제거한다.
4. 필요한 단어를 추출하고 `Counter` 등으로 빈도를 센다.
5. 한글 폰트를 지정해 워드클라우드를 생성한다.
6. 필요하면 이미지 마스크로 전체 모양을 설정한다.

주요 도구는 `wordcloud`, 한국어 처리를 위한 `konlpy`, 빈도 계산을 위한 `collections.Counter`다. 이미지 마스크 처리에는 이미지 라이브러리와 NumPy를 활용할 수 있다.

단어가 크게 표시된다는 것은 지정한 빈도·가중치가 높다는 뜻이다. 문맥이나 긍정·부정 감정을 직접 설명해 주는 것은 아니다.

## 9. Folium 지도 시각화

Folium은 위도·경도를 이용해 지도에 위치 정보를 표현하는 라이브러리다. 자료에서는 공공데이터와 매장 위치 등을 지도에 표시하는 실습을 다룬다.

### 기본 작업 흐름

1. 위도·경도가 포함된 데이터를 준비한다.
2. 지도 중심과 확대 수준을 설정한다.
3. 각 위치에 마커를 표시한다.
4. 이름·설명 등을 팝업으로 연결한다.

```python
import folium

stores = [
    {"name": "Store A", "lat": 37.5665, "lon": 126.9780},
    {"name": "Store B", "lat": 37.5700, "lon": 126.9820},
]

m = folium.Map(location=[37.5665, 126.9780], zoom_start=13)

for store in stores:
    folium.Marker(
        location=[store["lat"], store["lon"]],
        popup=store["name"],
    ).add_to(m)

m.save("stores_map.html")
```

`location`에는 `[위도, 경도]` 순서로 입력한다. 위치 정보는 결측 여부와 좌표 범위를 확인한 뒤 사용한다.
